# React To-Do List project 📝

A fully functional To-Do List application built using React that allows users to add, complete, delete, and track tasks with a clean UI and component-based architecture.

---

## 📌 Overview
This project is a complete React To-Do application focused on understanding state management, props flow, conditional rendering, and CSS Modules.

---

## ❓ Problem Statement
Managing dynamic lists and application state is a core challenge in frontend development. This project demonstrates how to build a To-Do app using React functional components and modern best practices.

---

## 🛠️ Tools and Technologies
- React.js
- JavaScript (ES6+)
- CSS Modules
- Vite / Create React App
- JSX

---

## ⚙️ Features
- Add new todo items
- Mark todos as completed (click to toggle)
- Delete individual todos
- Display **total** and **completed** todo count
- Auto-sort todos (pending first, completed last)
- Fixed header and footer layout
- Scoped styling using CSS Modules
- Clean and responsive UI

---

## 🧩 Components Structure
- **App** – Root component
- **TodoHeader** – Fixed header title
- **Form** – Add new todos
- **Todo** – Manages global todo state
- **TodoList** – Displays sorted todo list
- **TodoItems** – Individual todo item (complete/delete)
- **Footer** – Shows total and completed todo count

---

## 🖥️ Application Flow
1. User adds a todo using the input form  
2. Todo is added to the state and displayed in the list  
3. Clicking on a todo marks it as completed  
4. Completed todos move to the bottom of the list  
5. Footer updates completed and total todo counts in real time
